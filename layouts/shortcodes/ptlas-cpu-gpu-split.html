Pipeline ownership

Who does what?

GPU-driven does not mean CPU-free. Setup, authoring, and execution can live in different places.

CPU

Setup and orchestration

  • detect PTLAS support and pick backend path
  • choose partition layout and allocate buffers
  • record update/build commands
CPU or GPU

Sparse update authoring

  • detect changed instances
  • choose local partition or global partition
  • write changed records and operation counts
GPU

Execution and traversal

  • consume indirect operation buffers
  • execute the PTLAS update/build command
  • trace through the resulting top level
