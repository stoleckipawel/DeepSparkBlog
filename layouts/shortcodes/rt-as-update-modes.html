Classic TLAS maintenance

Instance motion usually means rebuild or refit.

Both are valid. They optimize different parts of the frame.

Choice A

Rebuild TLAS

Build the top-level structure again from the current instance set.

  • fresh structure quality
  • handles broad membership changes cleanly
  • more top-level build work
Choice B

Update / refit TLAS

Reuse the previous structure and update changed instance bounds or transforms.

  • can be cheaper for transform-only motion
  • requires update-compatible build setup
  • can lose traversal quality over time
Baseline: refit/update can reduce build work, but the maintained object is still one top-level structure.
