Classic TLAS maintenance

Choose where the frame pays.

Both paths maintain one scene-wide top-level structure. The difference is whether the frame pays in builder work or risks carrying layout drift into traversal.

Fresh layout

Rebuild TLAS

Build a new top-level layout from the current instance records.

Use when
Instance membership, BLAS references, flags, masks, or spatial distribution changed broadly.
Cost now
Higher build/update work and scratch pressure because the top level is constructed again.
Cost later
Traversal can recover from overlap or clustering created by previous motion.
Engine habit
Use as a checkpoint after many refits or after broad streaming / visibility changes.
Reuse layout

Update / refit TLAS

Keep the previous top-level layout and refresh compatible instance data.

Use when
The instance set stays compatible and most changes are transforms or bounds.
Cost now
Lower builder work because the previous top-level layout is reused.
Cost later
Traversal can degrade if moved instances no longer match the preserved layout.
Engine habit
Use for transform-heavy frames, then rebuild when trace cost or overlap drifts.
Baseline limit: rebuild and refit move cost between building and traversal, but the maintained unit is still one broad TLAS.
